# Student Passport Monitor 2.0 — WPF

Это рабочая ветка нового интерфейса. Основное приложение 1.x пока остаётся на WinForms, а WPF-версия собирается как отдельный проект.

## Запуск

```powershell
git fetch origin
git switch dev/v2.0.0
dotnet run --project src/StudentPassportMonitor.Wpf/StudentPassportMonitor.Wpf.csproj
```

Используется та же локальная база `%LOCALAPPDATA%\StudentPassportMonitor`. Перед первым запуском новой версии стоит сделать копию каталога с данными.

В WPF уже перенесены основные разделы, таблица студентов с поиском и фильтром, карточка редактирования, импорт и экспорт Excel, история проверок и настройки. Интерфейс адаптируется к размеру окна.

Это ещё не готовый релиз: нужно проверить сборку на Windows, доработать уведомления в трее, оформление статусов, тесты UI и установщик версии 2.0.0.
